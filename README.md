# Pancham G — Personal Portfolio

A responsive, dark-themed personal portfolio created for **Pancham G**, a BBA student at SBRR Mahajana First Grade College, Mysuru.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or package installation are required.

## Personalize before publishing
- Open `script.js` and replace `your.email@example.com`, `your-username`, and `your-profile` with your actual contact links.
- In `index.html`, update the GitHub button link and add a LinkedIn link if you want one.
- Add verified certificates, projects, internship experience, and a profile photo when available.
- Check every detail before publishing.

## Publish with GitHub Pages
1. Create a repository in your GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

This is a new ready-to-use portfolio build based on the details provided, not a direct modification of the linked repository's original files.
